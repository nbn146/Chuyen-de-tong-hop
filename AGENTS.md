## Before implementation

For each new task or request to improve earlier work, first inspect the relevant context and discuss the task with the user. Summarize the current problem, desired result, scope, proposed approach, and what would count as done. Ask focused questions about unclear requirements or meaningful tradeoffs. Wait for the user's reply before making implementation changes.

After the discussion, carry out the agreed work and share progress without asking for approval at every routine step.
